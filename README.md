# Savdochi Pro

Telegram orqali mahsulotlar, savatcha, buyurtmalar va omborni
boshqarish uchun Node.js + Telegraf bot.

## Talablar

- Node.js 20 yoki undan yangi
- Telegram bot tokeni
- Administrator Telegram ID raqami

## O‘rnatish

1. Terminalda loyiha papkasini oching.
2. Kutubxonalarni o‘rnating:

   npm install

3. `.env` faylida BOT_TOKEN va ADMIN_IDS ni kiriting.
4. Botni ishga tushiring:

   npm start

## Ma’lumotlar

Mahsulotlar, foydalanuvchilar va buyurtmalar `data.json` da saqlanadi.

Bu o‘quv va prototip loyiha. Ishlab chiqarish muhitida JSON fayl o‘rniga
MongoDB yoki PostgreSQL, xavfsiz tranzaksiyalar, zaxira nusxalari,
